# `results/ablation/` — four-condition frontier-scoring ablation

This directory holds the output of the four-condition ablation reported in
**Table II** of the paper (avg. info-gain per chosen frontier, and win/tie/loss
records, for `nearest`, `info_gain`, `heuristic`, and `diffusion` scorers).

## Regenerate

Run inside the ROS 2 Humble + `stage_ros2` environment (the same stack that runs
the Stage demo — see [`../../ros2_ws/README.md`](../../ros2_ws/README.md)):

```bash
# from final-project/
bash scripts/run_ablation.sh          # 4 methods x 10 trials -> results/ablation/{method}/trial_*.json
python scripts/analyze_ablation.py    # -> results/ablation/summary.csv, head_to_head.csv,
                                      #    info_gain_bar.png, coverage_curves.png
```

Use `bash scripts/run_ablation.sh --trials 3` for a faster (reduced-trial) run.

## Outputs

| File | Contents |
|---|---|
| `{method}/trial_N.json` | per-decision log for one trial (chosen frontier, info gain, coverage series) |
| `summary.csv` | per-method mean info-gain + W/T/L — the source for Table II |
| `head_to_head.csv` | pairwise diffusion-vs-baseline comparison |
| `info_gain_bar.png`, `coverage_curves.png` | the ablation figures |

> The trial logs are not committed (they are regenerated by the harness above on
> the grader's machine); this README documents how to reproduce them.
